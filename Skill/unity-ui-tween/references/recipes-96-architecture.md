# 96 条场景配方展馆

当前为 0.8.0-dev。目标仍是 12 类 × 8 条，旧 46 个基础预设及旧馆归档保留。本次按用户后续反馈调整页面组织：美术风格延续原型，构图服从当前案例的操作与观察重点。

## 页面与阅读顺序

左侧默认完整展开 12 类与 96 条；每类显示筛选数量 / 8，当前条目高亮。点击条目后滚到该类标题，便于确认当前位置。搜索、对象和状态筛选常驻目录上方，分类可手动折叠，不再默认显示少量快捷入口。

舞台固定为“效果名称 → 一句操作提示 → 观察提示 → 演示主体 → 场景操作 → 播放控制”。播放/暂停、重播、速度、时间轴只有舞台下方一处；更多菜单放循环、反向、重置和复制。场景内的“按下、松开、领取、删除”等是业务操作，不是重复的播放按钮。P 播放/暂停，R 重播；编辑输入框时不抢占快捷键。

右侧只显示当前配方参数、实时状态与对象/状态标签，另有验收、导出和接入说明。曲线显示实际 DOTween 求值；选择后重播已有迁移，不重复提交业务。不支持固定时钟、曲线或强度的案例不会展示可操作的无效参数。曲线采样点在未播放时静止。

## 标签与状态

`RecipeDefinition` 对每条配方显式记录 `objectTags`、`stateTags`、`typeTags`，目录筛选求交集，不根据分组编号推断。状态标签显式标注该配方的核心演示状态，不自动包含所有边界操作的可能状态；它表示该配方涉及的行为状态，不表示所有已访问舞台的瞬时状态。搜索同时检索名称、编号、素材与三种标签。

检查器读取场景实际 `DisplayStatus`：输入校验成功/失败、编辑中、按钮默认/按下/禁用，以及拖放接受/拒绝/取消。未专门翻译的状态使用场景自己的简短说明，不回退为“已选中”。配方规格的初始状态描述迁移起点；舞台尚未触发时显示实际就绪状态。

## 实现边界

`RecipeCatalog` 校验 96 个唯一编号与标签维度。`RecipeGalleryBootstrap` 管理目录、参数与统一控制。`RecipeStage.*` 持有真实操作和纯表现闭包；`MotionChannelArbiter` 管理对象/属性租约；`RecipeArt` 使用未修改的 imagegen PNG 和 Sprite 裁切矩形。

业务结果先确定，动画只负责表现。Seek 和 Replay 不发奖、不改变列表身份、不重复点击；重置恢复场景。Tween 在首次时间轴采样前完成初始化，避免把采样值误读为起点。输入跟手、解析弹簧、原生 ScrollRect、真实倒计时分别由各自模型驱动，不伪装为任意可逆的预制动画。

Unity 6000.0.26f1、UGUI 2.0.0、原有 DOTween 免费版。`scripts/recipes96.ps1 -Target Build` 生成 `Builds/Recipes96`，`-Target Validate` 在两个可见桌面窗口执行 96 条与代表案例检查。
