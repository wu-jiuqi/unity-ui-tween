# 从画风设计按钮

## 适用与选择

用户希望“用这个画风适配更多按钮”时，从形状、材质和交互语义开始设计。已有游戏截图是风格证据，不是限定只能使用其中的猫咪、毛线球、名称、活动和页面。新造型、新图标和新用途均可沿用同一视觉语言。

用户已经认可的原型优先于历史界面；原型定义视觉方向，历史界面用于兼容与接线。不要因为历史项目没有某种按钮就放弃制作新的变体。

本次奶油花园参考：暖奶油 #FFF8E9、薄荷 #A6DCC1、淡紫 #CCACEB、蜂蜜金 #EBC36D、深可可文字 #4B2C20、珊瑚 #F4AAA0。色值是起点，按最终背景对比度调整。浅浮雕边、柔软体积、左上柔光、小范围投影；金边用于主操作或重要入口。不要给所有按钮增加花朵、猫咪和奖励图案。重做整屏时先按art-composition-workflow.md确定文字与底板关系，再拆资源，避免只生成空白按钮后临时贴字。

先确定用途：主操作、次操作、圆形工具、图标入口、分类页签、开关或异步任务。随后分别选择形状、材质和反馈配方；不要把一种按钮造型与一种动效永久绑定。关闭、返回等高频工具宜小幅反馈，奖励和强调操作可有较明显回弹。选择与加载必须由真实业务状态驱动。

## 素材、布局与文字

背景、描边、投影、文字、图标、扫光和选中层按需要拆分。弹性较强的变形放在底板；密集中文、价格或重要图标可移到不变形的兄弟层，用较小的位移关联反馈。圆形按钮保留纵横比，避免拉伸成椭圆；文字尺寸与对比度在目标分辨率下检查。

外层承担布局和命中，内部 surface 负责视觉变形。图标 pop 使用 surface 的内部 icon；selected outline 可以作为 surface 的兄弟层。涟漪与扫光使用专门装饰层，并在需要的轮廓内裁切。装饰 Graphic 关闭 raycastTarget。不要让扫光矩形溢出圆角或遮住文字；不透明按钮可用独立 Mask 子树约束轮廓。

示范图集按固定区域截取，不是通用九宫格。用于不同长宽比时重新导出合适比例的素材，或为不含烘焙阴影的面板配置九宫格后检查四角。不能给整张图集直接设置九宫格或任意横向拉伸圆钮。

需要新美术时，明确正视角、统一光向、主体区域、透明留白、支点、独立高光/投影、文字留空及真实 alpha。保留来源与生成说明。图像生成是素材制作选项，已有合适资源时不必重新生成。

## 接到需求后的输出

给出“用途 → 形状/材质 → BX 配方 → 绑定层级 → 参数 → 打断行为”。用户只要效果时直接实现适量变体；用户先要方案时提供可比较原型。不要自动改写页面导航、货币、购买、解锁或任务状态。为当前请求选择需要的参考，避免把整个风格手册作为所有任务的前置流程。

验收至少包含实际尺寸、长文案、按住/移出/拖动、禁用和连续触发。静态美术图、关键帧和真实 Player 视频是不同证据。
