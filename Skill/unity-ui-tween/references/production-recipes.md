# 从单个动效到生产编排

本页补充 A01–F06 的宿主接线方法，不新增编号，也不声称这些配方已经成为 Runtime 组件。来自真实项目的静态对照见 [来源与覆盖矩阵](source-patterns.md)。按本次任务选读相关配方，不必为一个按钮引入整套页面控制器。

## 1. 先选运动模型与所有者

| 需求 | 适合的模型 | 当前可复用部分 |
| --- | --- | --- |
| 已知终点、固定时长的出现/切换 | Tween / Sequence | MotionPlayer、46 项预设 |
| 中途改终点，位置不能跳 | 从当前姿态接续 | ContinueTo；不保证速度连续 |
| 拖拽、频繁追踪移动目标，速度需连续 | 阻尼弹簧 | MotionSpring1D/2D、MotionJellyDrag |
| 多层同一时间轴、需要任意时间预览 | 纯时间求值 Render(time) | MotionPlayer.Sample；自定义内容需适配 |
| 手绘表情、角色动作或形变轮廓 | Sprite 帧 / 网格形变 + 上述模型 | 本页适配指南；不是现成 Sprite/网格播放器 |

给每个可写属性分配唯一所有者。例如页面入场用 PageVisual，列表重排用 RowPlacement，按压用 RowVisual，字形波浪用 Text 的独立适配器。布局、命中区、表现层分开；不要为了组合效果，让多个播放器并写同一位置、缩放或透明度。

从已有项目抽取时，不只搜索 `DOScale` / `DOTween`。同时检查 `Update` / `LateUpdate`、协程、`Lerp` / `Sin`、`BaseMeshEffect`、TMP 顶点和 Sprite 换帧。记录触发源、基线、时间源、终态、取消路径、音频、输入门槛与验证证据，避免把程序化动画漏掉。

## 2. 复合页面：阶段、就绪、跳过、取消

先写可调阶段表。例如“标题进入 → 主视觉冲击 → 奖励揭示 → 操作区淡入 → 可点击”；每阶段有起点、时长、控制的包装层。角色帧、粒子、声音、字幕和按钮都从同一页面时钟求值，而不是各自启动几个互不关联的延时。

页面应分开管理四件事：

1. **视觉求值**：给定时间得到位置、缩放、透明度、Sprite。倒拖、重复采样不发奖、不导航、不重复创建对象或播放音效。
2. **权威业务**：显示业务已确认的结果。若产品确需在确认时提交，用稳定操作 ID 和业务端幂等逻辑；不要把奖励保存绑在 Tween.OnComplete 上。
3. **输入就绪**：按钮可见不等于可点击。操作区 CanvasGroup 同时管理 `interactable` 与 `blocksRaycasts`，就绪后仍保留 Button 自身的业务禁用状态；背景遮罩单独阻挡穿透。
4. **一次性事件**：声音和“表现完成”通知走受播放版本保护的事件通道。MotionPlayer.Sample 只处理视觉，不能代替业务提交或完成通知。

自然结束和用户 Skip 汇入一个幂等的表现完成入口；Cancel/Disable 不是完成：

```text
Begin:   先取消上一轮；取新播放版本；锁操作区；建立本轮时间轴
Tick:    求值视觉；按同一时钟推进声音；到达操作区门槛后开放输入
Finish:  若版本过期或已结束则返回；先标记结束并使旧回调失效
         静默停止剩余声音；渲染必要终态；开放允许的输入
         最后通知宿主一次“表现完成”
Cancel:  先使版本失效；取消协程/等待/Tween/声音；解除本轮输入
         按页面约定恢复或隐藏；不调用 Finish，不产生领取/导航
```

`Finish` 要先失效旧回调，再调用宿主，因为宿主可能立刻打开下一页或重用对象。多层终态由页面统一应用。使用已有 MotionPlayer 的一层可 `Sample(1f)` 后 `ReleaseAtCurrentState()` 保持终态；先明确 reverse、循环与本次配置的“终态”含义，不能把反向动画的末帧误当打开状态。下一次显示须重新按页面业务状态初始化，不能把中间姿态当新基线。

隐藏的操作区可设置不拦射线，但模态背景应一直拦截底层页面。不要用隐藏按钮的透明度代替点击门控，也不要把所有子 Button 无条件设为可用。`MotionPlaybackGate` 可决定 Restore / CompleteImmediately，业务完成入口仍由宿主负责。

## 3. 时钟：保留节奏与追赶真实时间不是一回事

| 情况 | 时间策略 | 注意事项 |
| --- | --- | --- |
| 暂停后仍可操作的菜单/结算 | unscaled 时间 | 明确失焦、后台、隐藏时暂停还是结束 |
| 游戏内加分/击中反馈 | 游戏模拟时间与暂停条件 | 与对应游戏状态一起冻结；不要只看 Time.timeScale |
| 加载刚结束的可读入场 | 可选独立表现时钟 | 首次可见后再起计，可跳过首个准备长帧或限幅 dt；会延长墙钟总时长 |
| 倒计时、截止时间、真实进度 | 权威时间/真实任务进度 | 不按动画进度伪造完成，不用限幅 dt 隐藏超时 |
| 弹簧/带速度状态的模拟 | 完整经过时间 | 用现有解析 MotionSpring；不要照搬逐帧 dt 限幅 |

如果选择可读性优先，可由宿主在首帧完成布局后设 `presentationTime=0`，之后累加有上限的 dt。上限是产品节奏选择，不是通用性能优化；帧率持续很低时必须提供 Skip、减弱动效或直接落终态，避免用户一直等不到操作。业务加载完成条件单独检查。

自管时钟不会自动控制 MotionPlayer.Play 的 DOTween 时间。选一种驱动方式：常规固定时长效果由 Play 自主推进；自管/限幅页面时钟则先绑定并配置每层 effectId/settings、捕获稳定基线，再每帧调用 Sample(localNormalizedTime)。单次阶段可用 `Clamp01((presentationTime-start)/duration)` 求局部进度，零时长直接求终态；循环与速度映射由宿主明确定义。不再同时靠 Play 自主推进这些层；暂停时保持页面时钟不变。该 Sample 路径不产生完成事件，Finish 与声音 Advance 都由同一宿主时钟管理。

音效用同一个所选表现时钟调用 `MotionSoundTimeline.Advance`。视觉限幅而声音用墙钟，会在卡顿后先响完再播放动作。Seek/Sample 不触发声音；暂停不积压需要补放的节点；恢复时明确是否追赶，避免一次长帧补响所有装饰声音。对必要通知与装饰音可以制定不同策略，但应显式实现，不能假设 Runtime 自动完成。

## 4. 高频触发：重播、替换、合并、队列

| 事件 | 策略 | 结束条件 |
| --- | --- | --- |
| 普通点击反馈 | 重播或当前姿态接续 | 保证回基线，不能越按越大 |
| 分数总值/进度目标变化 | 替换目标 | 从当前显示值趋近最新权威值，旧终值失效 |
| 短时间大量加分/收集 | 合并视觉增量 | 固定窗口，或静默窗口 + 最大等待 |
| 每条必须读到的结算 | 有界队列 | 设容量/优先级与溢出处理；装饰反馈可以合并或丢弃 |

视觉聚合不推迟实际记分。收到事件时业务立即更新，表现层只累加待显示增量。一个可调整的起点是静默窗口 70ms，另加最大等待 200ms；它们是调参示例，不是默认组件参数。只重置静默窗口而没有最大等待，在持续事件流下会无限推迟飘字。

```text
收到本轮正增量:
    若本批为空，记录 firstAt
    pending += delta；lastAt = 同一表现时钟的当前时间
每帧:
    若 pending 非零 且 (now-lastAt >= quietWindow 或 now-firstAt >= maxWait):
        先取出并清空 pending，再发起一次飘字（防回调重入）
```

变化可能来自回档、退款或新的游戏会话，不能一律视为“奖励”。订阅会话/页面版本，换会话时重置 seen 与 pending；负增量按产品语义立即刷新或单独表现。取消后丢弃待播视觉，不回滚权威值。暂停时冻结本轮时钟或明确 flush，减弱模式直接刷新数字。合并后的总数、格式化与整数范围必须使用业务认可的数值类型。

接收端强调用 D10，飘字用 D09，总数用 D01 或 TmpMotionAdapter。批量飞入可减少代表性图标数量，但实际总数不能随可见图标数量改变。并发上限、池租约与页面取消继续遵守 [编排与生命周期](orchestration.md)。

## 5. 数据驱动列表：身份稳定、重排不跳、点击对象不串

以业务稳定 ID 保存行实例，不能以当前索引识别排行榜或任务条目。先取得完整新快照并计算所有目标位置，再更新可见行：

- 新增行明确从最终位置显示还是入场；删除行取消自己的移动与异步回调后回池。
- 已有行仅在位置/内容变化时更新。重排先终止旧移动且不恢复旧位置，再从当前显示位置过渡到新目标；频繁变化需要速度连续时选弹簧。
- RowPlacement 负责重排，内部 RowVisual 负责命中/弹性；不要用同 target 多播放器“组合”。按住期间身份不可改绑；对象池重借必须更新点击与异步 token。
- 保留玩家滚动位置/可见锚点，不在每次刷新都自动聚焦自己；拖动列表时由 ScrollRect 拥有输入。
- LayoutGroup 管理的列表用布局槽位 + 内部偏移层：重排前记录屏幕位置，布局完成后计算相对新槽位的视觉偏移，再衰减到零。不要与 LayoutGroup 争写 anchoredPosition。

ContinueTo 只保证当前姿态到目标的连续插值，并不是完整的列表 diff、布局或虚拟化组件。大列表先复用目标项目现有虚拟化方案。

## 6. Sprite 帧与 Tween 混编

角色表情或手绘冲击可以使用每帧不同停留时长；外层 Tween 只负责位置、整体缩放、透明度。先核对动作是否已把跳跃位移画进帧里，避免再给外层加一次相同跳跃。

维护一份 `帧资源 + 持续时间` 数据，生成累计边界。单次播放负时间取首帧，达到总长取末帧；循环才对总长取模。边界规则统一为左闭右开，持续时间应为有限正数。长帧通过当前总时间直接选帧，不能每个 Update 只递增一张；预览、运行与音轨共用同一份时间定义。

所有帧保持一致画布、比例和注册点，例如脚底基线。不要按每帧非透明像素重新裁切后直接替换，否则会抖动。缓存 Sprite/图集引用，不在每帧 Resources.Load 或 Sprite.Create；对象销毁时按所有权释放自行创建的资源。检查图集内存、过滤、压缩、透明边与遮罩过绘。

本包没有通用 Sprite 帧播放器，也不带源项目角色图。此类需求应在目标工程写小型适配器，使用用户有权使用的资源；不要把帧动画宣称为一个 Ease 或直接从私有项目复制素材。

## 7. 逐字揭示、字块编排、顶点形变分别实现

- **逐字显示**：优先 TmpMotionAdapter.Reveal 的 maxVisibleCharacters，保留完整字符串和富文本；不逐帧截断字符串或标签。
- **独立字块错峰**：E05/F03，可分别旋转和移动 RectTransform。顺序明确是作者数组、阅读顺序还是空间排序，多行文本不能简单只按 x 排序。
- **TMP 字形波浪**：读取 textInfo，跳过不可见字符，按 materialReferenceIndex 与 vertexIndex 找到实际子网格；从未变形顶点副本求值。文本、字体、换行、布局或材质变化后重建缓存，停止时恢复原顶点。每帧在上帧结果继续加偏移会漂移。
- **UGUI 果冻剪切**：可由 BaseMeshEffect 在自己的 Graphic 上改顶点；跨嵌套对象时先变到共同形变空间再变回。命中区不跟着变形，遮罩边界与文字可读性要单独检查。

后两者不是 TmpMotionAdapter 已提供能力。Bounce 的部分实现每帧 ForceMeshUpdate 或 SetVerticesDirty，这是实现路径，不是性能推荐。仅在内容或形变改变时重建/标脏，静止或不可见时停止；如 TMP 自身重建网格，应用形变的时点要避免被其覆盖。长文、中文、富文本、emoji、多个材质、字体回退与减弱模式都需实测；不要宣称按 char 拆分等同 Unicode 字素簇。

## 8. 空闲提示与教学动画

空闲提示应有静默间隔，而不是无间断高频弹跳。结合按住/悬停、近期输入、页面可见、滚动视口、弹窗、导航、失焦与减弱模式门控；被打断后重置空闲等待，不要恢复时集中补播。波浪/呼吸可用包络让每次动作自然回基线，再进入静默段。

教学演示使用独立假数据和展示对象；拖动时间轴、循环和 Skip 不得给真实游戏发射、扣次数、发奖或修改进度。若引导跟随真实目标，只读取位置和当前状态，真实操作仍来自玩家；装饰层关闭 raycast，用户开始输入时立即让路。MotionPlaybackGate 的宿主条件不是自动空闲计时器，E07 也不会自动推进教学状态。

## 9. 跨空间引导与奖励落点

先选表现坐标系：UI 内部飞行、世界物体飞向 HUD、世界目标上的 UI 引导是不同适配。不要把世界单位直接赋给 anchoredPosition，也不要硬编码乘 100 当通用转换。

- 世界 → UI：先用来源世界 Camera.WorldToScreenPoint，再用目标 Canvas 对应 camera（Overlay 为 null）及目标父 RectTransform 的 ScreenPointToLocalPointInRectangle。检查相机后方、裁剪与转换失败。
- UI → 世界：先用 UI camera 取得屏幕坐标，再与游戏中指定深度/平面求交；透视相机不能把 ScreenToWorldPoint 的 z 随便设为零。
- 本地转换结果相对父级 pivot；若飞行对象使用 anchoredPosition，确认其 anchor reference 与该原点一致，或显式换算。绑定到稳定的视觉中心，不假定所有 pivot 居中。
- 目标会随安全区、布局或滚动移动时，明确起飞时冻结落点还是持续追踪；追踪时从当前姿态改目标，不能突然重置整条飞行。

D03/D04 的 UI 奖励与 C04 的同 Canvas 变形不能自动完成上述相机/平面适配。屏幕转换需在布局稳定后执行，测试 CanvasScaler、非默认 pivot、相机变化、屏幕旋转、目标消失和取消；数字刷新读权威值，飞行抵达只负责表现。

## 10. 生产回归的最小集合

按本次使用的配方选测，不能用静态源代码对照代替运行：

1. 同一时间重复采样及倒序采样，视觉一致，无保存/发奖/声音副作用。
2. 自然完成、连续两次 Skip、关闭、禁用和回池后旧回调到达；只允许本轮完成一次，取消不完成。
3. 操作区淡入前/中/后点击，业务禁用按钮仍禁用；模态背后无穿透。
4. 准备时注入长帧、持续低帧率、暂停与后台恢复；画面/音效跟随明确时钟，真实倒计时不被限幅。
5. 连续事件超过静默窗口且持续数秒；最大等待仍触发批次，总增量正确，换会话无旧飘字。
6. 列表连续交换名次、删除/插入、按住时刷新及滚动中刷新；对象身份、点击结果和滚动锚点保持正确。
7. Sprite 边界/循环接缝，TMP 动态文本/换行/材质重建，停用后复位与禁用反馈后的必要终态。
8. 按实际坐标系测试移动落点、屏幕边缘、安全区和对象销毁；测试所用平台、分辨率、日志与未运行项见交付报告。
