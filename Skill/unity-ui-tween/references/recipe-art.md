# 96 条配方的原型与分层美术

美术按“imagegen 原型 → 独立图层 → Sprite 拆分 → Unity 重新拼装 → 运行画面对照”制作。用户指定的[卡牌与拖放原图](../ArtSource/Recipes-v070/approved-reference.png)保留为素材与风格基准；另三张是素材家族探索，不代表用户逐项确认。

0.8 根据后续反馈改为按案例聚焦：拖放场景不显示三张大卡牌，翻面只保留一张主卡，循环场景改用独立图标。复用现有 117 个 imagegen 部件，不新增装饰填充空白。工作台、分隔条和曲线图使用必要的原生 UI 结构，游戏对象继续使用生成的分层位图。旧 0.7 构图保留在 Git 历史和 v070 截图中，当前画面见 v080。

卡牌人像使用原始 Sprite 裁切，卡框、标题、稀有度和宝石独立；宝箱箱体/箱盖、按钮底板/图标/高光等仍可独立运动。未把整页原型作为背景伪装成交互画面。

- [按钮与输入](../ArtSource/Recipes-v070/prototypes/controls.png)：高饱和按钮、独立图标、开关、复选、单选、输入与滑块。
- [面板与导航](../ArtSource/Recipes-v070/prototypes/surfaces.png)：面板、抽屉、菜单、气泡、任务行、页签与进度。
- [卡牌与拖放](../ArtSource/Recipes-v070/prototypes/cards.png)：卡牌正反面、插画、稀有度装饰、物品与不同插槽。
- [奖励与反馈](../ArtSource/Recipes-v070/prototypes/rewards.png)：独立箱体/箱盖、货币、星级、成就、等级、排名与提示图标。

四张原型统一采用高饱和蓝、橙、绿、紫和暖金，圆润体积、上左光源、清楚轮廓。原型中的工具框架仅作构图参考，实际展馆继续采用确认的安静中性色和简洁三栏。生成图中的说明文字和虚构目录不进入真实配方数据。

## 引擎拆分与组合

`scripts/register_recipe_art.py` 只读取 PNG 并分析 alpha 连通区域，输出每个部件的矩形与九宫格边界，不重绘、不抠图修补、不修改生成像素。读取实际输出尺寸，避免假设工具总返回固定分辨率。所需分析依赖为 Pillow、NumPy、SciPy。

`RecipeArt` 使用 manifest 的矩形创建缓存 Sprite。面板与普通按钮按九宫格拉伸；图标按比例显示；卡框保留整体比例，人像按定稿窗口的坐标与比例匹配，避免缩成卡片中央的小贴图。普通文字、数据、状态、输入与数值为原生 UGUI Text；固定工具图标从原型精确裁切。遮罩、命中区和模态遮挡由原生 UGUI 管理。

材质中心必须能承载文字，透明仅用于外轮廓或明确的光效、镂空轮廓。生成图中极低 alpha 的边缘光不作为主体边界；裁切保留主体和必要抗锯齿。原型、拆分图集和实际拼装分别保留，以便复核。

## 检查范围

检查实际显示尺寸的文字安全区、边框、高光、插画比例、卡牌正反面、箱盖枢轴以及移动峰值的裁切。96 个场景分别导出运行截图；截图不替代真人体验。当前目标为桌面横屏，本机 Windows 运行验证与其他平台的未验证状态分开记录。
