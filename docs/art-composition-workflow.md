# 先整图定稿，再拆素材拼装

当目标是按项目画风重做界面、文字与背景不协调，或用户明确要求 image gen 参考图时，先完成整屏参考，再拆素材并在运行界面还原。单改字色、在现成底板上临时贴字，不能代替这项流程。已具备合适定稿和素材的小修改可直接复用，不为每次改参数重新出图。

## 1. 整屏参考决定文字关系

参考图同时包含最终文案、标题层级、按钮主次、数值、选中态、背景和适配尺寸。输入原画风与现状截图，明确哪些是风格参考、哪些需要修正；完整排版图应能说明字放在哪里、由什么底板承载、与高光和描边保持多少距离。先检查中文正确性、原型中虚构的编号/功能和拥挤位置，再作为制作依据。生成图里的错误标签不进入正式目录。

本次主参考是源仓库ArtSource/Composition-v061/01-achievement-reference.png、02-responsive-reference.png；完整Skill中的副本位于assets/Reference/Composition-v061，Runtime包不带这些图片。主色仍为奶油、薄荷、淡紫、暖金，但正文改为深可可 #4B2C20，辅助文案 #76513E，主要按钮 #234B2B，淡紫文字 #502C4D。数值与正文有平静、明亮的底色；边缘光照不穿过字面。固定标题采用手工质感，控件文字保持清楚。目标是整屏关系一致，不能只让单张素材漂亮。

## 2. 明确文字采用哪种资源

| 内容 | 默认载体 | 拆分要求 |
|---|---|---|
| 品牌、固定艺术标题 | image gen 独立带字 PNG | 准确逐字核对、真正透明外轮廓、保持纵横比；图与可读文本语义分别保存 |
| 固定标题且需本地化/经常变化 | 空白标题底板 + 原生文字 | 先在整图里确定字形、字重、颜色、位置，再匹配字体；装饰不挤压安全区 |
| 普通按钮、标签、说明 | 原生 Text / TMP | 使用实际字体字重，避免合成粗体糊字；保留足够内边距和多语言空间 |
| 货币、价格、计数、进度 | 原生动态文字 | 不烘焙数值；字体与底板分别验收，变化不推动按钮布局 |
| 逐字动画的艺术 Logo | 各字独立 PNG / 规则图集 | 从生成阶段要求每个字独立；不能从带花朵、共享背景的整行标题随意切块 |

本次“动效图鉴”品牌和“旅程达成”标题是独立图形字；“选择奖励”放在空白缎带上，用原生文字；奖励数值、按钮文案、右侧参数和目录仍为原生文字。Logo 掉落使用新生成的四格独立字图集，不拆品牌牌匾。生成文字资产是有明确用途的选择，不强制将全部 UI 文案图片化。文字图片需要宿主另存语义文本并考虑本地化/可访问性。

## 3. 拆解资源清单后生成

每个资源记录：整图中的角色、路径、是否含文字、实际尺寸、透明范围、显示尺寸、九宫格边界、文字安全区、固定/动态状态。提示词引用同一主参考，统一光向、材质、描边和投影；完整成图不直接用作不可交互的界面截图。

本次拆成三色空白按钮、实心奶油底板、品牌牌匾、带字成就缎带、空白缎带和四格 Logo 字图集。细节与提示词在 ArtSource/Composition-v061。奶油按钮的安静中部也作为可拉伸面板使用，复用同一材质；Sprite 九宫格保留完整圆头，不能把弧形中段拉成尖角。实心方形底板用于文字演示舞台，其边缘不承担透明外轮廓。

## 4. 先验素材，再接 Unity

检查真实像素和 alpha，不只看缩略图。实心底板中央必须实心，透明仅在外轮廓之外；灰黑脏晕、中央透明洞、伪棋盘格、缺字和跨格污染均须退回重生成。此次两张中央 alpha=0 的底板已拒收，没有接入。最后分别生成实心方形底板与内部实心、外轮廓透明的奶油组件，避免将镂空边框当承字面板。

保留原始 PNG，不用 SVG 或程序色块替代承诺的美术。九宫格、Sprite 裁切和遮罩属于引擎接入；不用抠图脚本偷偷修补生成失败的中心或错字。读取实际输出尺寸设置裁切，不能假设工具一定返回提示词所写尺寸。用 scripts/check_composition_art.py 验证当前素材合约；新素材按自身清单更新检查，不照搬本例坐标。

## 5. 分层拼装并对照运行结果

按固定命中/布局 → 底板 → 原生文字/独立艺术字 → 图标 → 装饰 → 动效层拼装。文字避开边框和高光，先检查静止态，再检查按压、选中、加载、禁用和动效峰值。共享换肤不能把所有文字降为同一浅色、同一细字重，也不能覆盖单独规定的按钮字色。

在实际显示尺寸对照主参考的文字大小、字重、留白、主次关系和素材比例；检查短屏/长屏/横屏及长文案，不只比较配色。静态样式可参考正文对比度4.5:1、大字3:1的设计目标，同时检查生成字的边缘与局部背景；这些数值不能代替对完整合成画面的观察。需要循环动效时另看播放或采样视频，完成态截图不能证明运动节奏。

交付应包含主参考、拆分清单、独立素材、提示词/哈希、运行画面、实际通过和未验证的范围。若还没有视觉比对，就明确尚未验收，不能仅凭编译通过称已还原原型。
