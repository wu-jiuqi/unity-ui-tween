# 进阶动效参考与原创转化

本项目仅借鉴公开案例的运动设计原则；六项使用原创形状、文字与配色，不复制原始素材。来源中没有明确描述的星图或传送门，不视为原站视觉。

- **F01 全息扫描揭晓**：[Animation in the League Client](https://www.riotgames.com/en/news/animation-league-legends-client)。借鉴客户端战利品场景的分层动画与焦点建立，原创改造为几何卡片、扫描带和信息显现；不使用原游戏素材。
- **F02 星图解锁**：[VALORANT 0.50 patch notes](https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-0-50/)。仅借鉴契约升级与解锁反馈的设计意图；星图、汇聚与徽章为本项目原创，并非源游戏所述视觉。
- **F03 动态排版标题**：[Making Stagger Reveal Animations for Text](https://tympanus.net/codrops/2020/06/17/making-stagger-reveal-animations-for-text/)。借鉴文字错时揭示原则，原创改造为鲜艳游戏标题、独立字块与底线编排，不复制源码和版式。
- **F04 分层仪表板**：[Rovo motion](https://atlassian.design/rovo-ui/motion)。借鉴标题、内容和卡片的视觉先后，原创设计信息卡与进度条的因果编排。
- **F05 磁吸焦点轮播**：[Material Design Awards 2019](https://design.google/library/material-design-awards-2019)。借鉴 Reflectly 案例轮播升层和选择状态，原创改造为焦点卡、新旧卡及候选的权重转换。
- **F06 门户奖励揭晓**：[Animation in the League Client](https://www.riotgames.com/en/news/animation-league-legends-client)。借鉴奖励界面的分层视觉庆祝；传送环、碎片和奖励核心为本项目原创，原文未描述传送门。

## 用户提供的补充参考

以下链接以作者描述、示例项目说明或用户提供的入口作为研究依据，未逐帧核验其演示；各项目的画面和脚本均未复制。

- F01 方块/遮罩揭示：[Codrops BlockRevealers](https://github.com/codrops/BlockRevealers)；抽象色块揭示的节奏，转为原创扫描卡片。
- F03 逐字符编排：[TypographyMotion](https://github.com/codrops/TypographyMotion/)，以及 [作者文章：错时文字揭示](https://tympanus.net/codrops/2020/06/17/making-stagger-reveal-animations-for-text/)。参考错时与阅读顺序，原创标题内容和版式。
- F05 轮播焦点层级：[Material Design Awards 中的 Reflectly](https://design.google/library/material-design-awards-2019)；另查阅 [Rapid Image Hover Menu](https://tympanus.net/codrops/2020/07/01/creating-a-menu-image-animation-on-hover/) 的悬停视觉跟随概念，示例图片标注 CC BY-NC-ND，本项目不分发或复制图片。
- F05 卡片层次另参考 [Balatro 卡片鼠标悬停研究](https://www.wavebeem.com/toybox/2025/balatro/) 的多层反光描述；卡图与几何层为原创。仅当实现经实际测试时，才能宣称支持鼠标悬停，自动播放演示不能代替真实输入验证。
