# 展馆预览与美术（0.4.0）

当前为 0.4.0 正式版本，配套资产与发布状态以 GitHub Release 为准。

## 时间轴

播放区右侧现在是可拖动时间轴。拖动后暂停在所选位置；点击“继续”从该位置继续，不会跳回之前的时钟。也支持从终点往回拖动，以及三项对比同步定位。再次播放/改参数会从起点重播。原有 `Sample` 仍仅用于确定性采样，新的 `MotionPlayer.Seek` 才对齐实际播放时钟。

## 参数 JSON

右侧“复制参数 JSON”将 schemaVersion、动效 ID 与完整 MotionSettings 放入剪贴板。对比模式会包含全部对比 ID。可保存为 .json 或交给 Codex 接入。它不包含场景绑定、个人信息或本机路径；目前没有自动导入按钮。

## 美术

新增三张 image gen 生成的 PNG：奖励宝箱、能量水晶和冒险世界。正式资源位于 `Assets/TweenGallery/Resources/MotionArt/`，导入为 Sprite，按需缓存，不会为每个预览重复创建纹理。

- 宝箱用于 A03/A04/A05/C01 成功卡和 B05 礼物。
- 水晶用于相关奖励、卡片、悬浮和进阶展馆示例。
- 世界插画用于 A08 纹理模糊和 A06/D07 卡片。
- 按钮、圆角背景、图表与需要分层动画的 D08 箱体保留可编辑 UI 几何，它们是功能结构，不冒充生成美术。

所有 46 个现有 Prefab 保持原始序列化文件，避免损坏外部覆盖；本轮更新的是运行时生成的展馆示例和可单独复用的美术。旧 Prefab 不会自动换肤，接入项目可自行把新 Sprite 绑定到 Image。

生成提示词、文件尺寸与透明度检查见 `art-generation-v040.md`。视觉截图和测试以 `validation.md` 的实际记录为准。

## 范围

展馆仍是桌面横屏工具，并未宣称竖屏、安全区或移动触摸适配。当前没有连接 Android 设备，Unity 仅安装 Windows 构建模块；未执行移动端构建、移动 Profiler、真机切后台或真机触控测试。
