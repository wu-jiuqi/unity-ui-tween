# 0.6 页面美术与原型

按认可的三张原型实现：ArtSource/Skill-Next-Concepts-v1 中依次为三档动效、整页编排、响应式交互。原始提示词随图保留，不将原型大图直接当作可点击界面。

使用内置 image_gen 生成并保留透明 alpha 的三张实际 PNG；没有 SVG 占位，也没有将文字或业务标签烘焙到图中：

- cream-panel.png：1254×1254，奶油细金边底板，112像素九宫格边界。主展馆面板、新页面弹窗和卡片实际使用。
- achievement-medal.png：1254×1254，金色幼芽勋章、淡紫底衬和绶带，用于P01主视觉。
- reward-icons.png：1254×1254，星星/幼芽/宝石/金币四格透明图集，每格627×627，用于奖励卡和归集金币。

精确生成提示词及SHA-256在ArtSource/Style-System-v060/prompts.json、manifest.json。请求提示词以1024方图描述构图，工具实际返回1254方图；导入和图集切割以实际像素为准，未缩放或重新编码透明原图。导入器关闭mipmap、无压缩、clamp，保留原尺寸。

新页面按钮复用公共六款PNG皮肤中的薄荷、淡紫、奶油描边，背景沿用花园插画。所有文字、图标、装饰、命中层和动画层独立。完整Skill和Windows包带演示美术；Runtime包不包含这些图片，宿主可延续画风生成更多按钮、图标和页面资产。
