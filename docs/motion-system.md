# 统一动效选型与优化

0.5.0-preview3 以用户认可的奶油花园原型为视觉方向，统筹更新原有 46 项以及按钮状态配方。入口按用途组织，编号保留为调用键。主展馆统一选型、公共素材、自动播放、真实操作与导出；没有独立实验室/工坊入口，见 [操作流程](gallery-workflow.md)。

## 按需求选择

| 用途 | 可采样的时间轴模板 | 实时交互与变体 |
|---|---|---|
| 内容出现、退场 | A01 淡化；A02 滑入；A03 平滑缩放；A04 轻弹出；A05 位置落弹；A06 翻入；A07 裁切揭示；A08 清晰揭示 | 弹窗和图标按材质选强度，不全部套弹簧 |
| 按钮按压与反馈 | B01 轻压；B02 压缩回弹；B03 呼吸；B04 错误抖动；B05 摆动；B06 冲击 | BX01 柔软按住、BX02 果冻变形、BX03 悬停抬升、BX04 独立图标；B03–B06 用作有语义的提示 |
| 选择、状态与加载 | B07 选中交接；B08 开关滑动；E02 加载旋转 | BX07 真实选择、BX08 真实忙碌；视觉必须服从宿主状态 |
| 页面、容器切换 | C01 面板落位；C02 抽屉；C03 折叠；C04 共享元素；C05 同轴；C06 顺序淡化；C07 交叉淡化 | 根据导航方向和两页是否需要同时可见选择 |

B01/B02 是可 Sample/Seek 的时间轴表达，BX01/BX02 是按住/松开驱动的真实输入状态。按需求选择同一反馈家族的变体，不把它们叠加到同一层。E03 和 BX06 分别用于完整时间轴与点击事件扫光。实时状态层独立于外层入场层。

## 全量调整

- 原有 46 项重新配置 duration、strength、distance、stagger：高频按钮和页面更快、位移更小；装饰循环更慢、幅度更低；奖励保留足够时间和错峰层次。
- 默认 overshoot=1.1，B02 与真实 SetPressed 松开使用一次柔和 OutBack 回弹，替代连续 OutElastic 振荡；A05 继续保留位置 Bounce 的独立特征。OutElastic 仍可由用户显式选择。
- B07 前后选项的缩放均受 strength 控制，降低未选项发灰；B08 与 D06 的状态色来自 MotionSettings.inactiveColor / activeColor，不再把深蓝和荧光绿硬编码为所有项目的状态色。
- 展馆外框、全部 DemoFactory 示例和主展馆实时预览使用同一奶油/薄荷/淡紫/暖金系统。原 B 类主按钮复用原创材质；其余面板、字体、阴影与描边同步升级。
- 46 个预设与 Prefab 中实际序列化的数据都会更新，不只改展馆截图。原 Prefab 的既有对象与组件 fileID 保留，允许添加描边等视觉组件；更新模板仍应先检查下游 overrides。

## 接入项目的选择

以 MotionCatalog / Presets 的最新推荐参数起步；用户明确提供过参数时保留用户设置。仅升级代码不会自动覆盖业务自己保存的 MotionSettings。视觉由宿主美术决定；GalleryTheme 用于示范和模板制作，不强制给宿主 UI 换肤。

希望使用旧节奏时可使用已发布 v0.4.0 的预设或明确配置参数；编号一致不代表默认手感完全一致。需要持续弹簧或速度接续时选择 MotionSpring / BX，固定时间轴保留确定性采样能力。

新项目先做一套主操作、次操作、图标工具和状态控件，再沿同一材质扩展弹窗、页面和奖励。验收应覆盖完整目录、真实输入、视觉对比和导入后的 Prefab，不以增加示例数量代替优化旧内容。
