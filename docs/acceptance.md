# Codex 提示词与验收手册

## 从展馆复用

调参后复制提示词，补充真实对象和触发事件。保留编号、时长、强度、位移、间隔、曲线、速度、反向、循环、时间来源。图鉴提供 46 项逐条提示词。

> 使用 unity-ui-tween，为 Canvas/Victory/Visual 接入 A04 弹出进入，duration=0.35、strength=0.7、ease=Preset、loop=false、unscaledTime=true。只动画 Visual 包装层，保留 Victory 根的 LayoutGroup 和领取逻辑。连续打开先取消本实例动画并恢复基线，关闭或销毁时清理。实际编译并测试快速开关、游戏暂停和不同分辨率，报告未验证项。

组合示例：

> 胜利弹窗用 A04，按钮用 E05，按钮间隔 0.08 秒。用不同视觉包装层，由页面控制器编排；不修改全局 Time.timeScale 或停止其他 Tween。关闭时取消本页播放，重开从稳定基线开始。

> 金币领取用 D03 飞入金币栏，接收端用 D10，数字用 D01 更新到业务确认的最新值。动画中断不能重复发奖。起终点在同一 Canvas；不同 Canvas 时先补坐标映射。

## 参数复现

1. 展馆与目标项目使用相同 Runtime 和 catalog 版本。
2. ID、参数与基线一致，位移按 CanvasScaler 的参考坐标解释。
3. 核对绑定、父级空间、pivot、布局与填充方式。
4. 先用 Preset 确认效果，再修改 Ease。曲线改变节奏，不改变动画属性。
5. 先重播默认值，再比较改动；0.25x 慢放只作用于本实例。

## 通用检查

| 检查 | 合格行为 |
|---|---|
| 基本播放 | ID 与图鉴相符，有明确起止状态 |
| 连续重播 | 快速触发 10 次不累积位置、尺寸、角度误差 |
| 暂停与恢复 | 保持当前状态再继续，不影响其他对象 |
| 中断与关闭 | 停止/禁用后恢复基线，无遗留 Tween 或异常 |
| 销毁 | 动画中销毁对象没有持续异常 |
| 再启用 | 对象池复用或重新显示可再次播放 |
| 布局缩放 | 1280×720、1600×900、1920×1080 无错位、文字裁切 |
| 点击遮挡 | 不可见组不拦截输入，不擅自开启原来禁用的交互 |
| 局部所有权 | 不同 target 的 A/B 播放独立；同 target 的新 Play 或 SetPressed 取代前一个播放器 |
| 特殊绑定 | 遮罩范围正确、翻面不留镜像字、飞行准确命中目标 |
| 复制参数 | 复制内容与当前值一致，恢复默认匹配 catalog |
| 覆盖 | 46个基础编号、文档、预制体、预设无缺漏；另按下文分别验收57个展馆选项和独立复用能力，不把57视为MotionPlayer编号数 |

## 0.6扩展能力验收

当前展馆选项为46个基础效果 + T01–T07 + P01/P02 + G01/G02，共57个。BX配方和其他辅助组件另行检查，不改变这一计数。此表是验收要求，不是已通过结果；本次复查与变更须重新记录静态检查、编译、Player播放和真实输入的证据，未执行项标“未验证”。

| 能力 | 必查行为 |
|---|---|
| T01/T02整体/逐字弹跳 | 只动visual不动布局slot；错峰与总时长一致；反复播放、布局改变后重采基线无漂移 |
| T03 Logo与网格形变 | 最后一个字落稳后才进入共同衰减；原scale/rotation/pivot保留；禁用后变换和Graphic网格恢复 |
| T04/T06颤动与波浪 | 首页短促强调保留安静间隔；加载随实际任务及可见性调度；后台暂停或取消按宿主契约执行，不重复推进Step |
| T05文字显现/TMP适配 | 静默Seek不发完成；文字内容和布局不被改写；复杂字符/RTL说明适配边界；TMP数字/百分比/Reveal使用可选适配器，顶点波浪不误称已提供 |
| T07滚动提示 | 完整进入并离开RectMask2D；长文本裁切与队列由宿主处理；减弱动效静态可读，不把必要信息直接移出屏幕 |
| P01整页编排 | 各阶段顺序、不同父层金币落点、原有输入禁用状态；完成每轮一次；Seek/重播不发奖励；关闭/回池只恢复视觉与拥有的输入状态 |
| P02响应式布局 | 窄屏、宽屏、安全区与内容变化后仍可读可点；先Restore再重排/重采，不把它作为MotionPlayer时间轴 |
| G01/G02及BX输入 | 真实按住、拖动、移出、释放、取消、遮挡和禁用；ScrollRect与按钮事件不重复消费；中途改目标按约定接续，不冒称固定时长Tween速度连续 |
| Sprite离散帧 | 首帧、边界前/边界点、末帧及Restore；旧fps配置保持行为；若启用本轮拟补非等时帧，检查总时长、重复sprite、合法时长及每段停留，测试未执行不得标通过 |
| Confetti装饰 | 相同seed采样稳定、不改全局随机数；预分配对象末帧透明，Restore回基线；不声称提供对象池或物理 |
| 声音时间轴 | 真实正向播放跨节点一次；长帧跨多节点；暂停/后台/速度与视觉时钟一致；Seek/反向静默，Skip取消后续声音；只停止ownedSource |
| 租约与播放条件 | 旧播放、旧对象池借出和旧页面回调不得写回；隐藏/模态/导航时停止相应交互；减弱动效保留必要状态且不重复提交业务 |

所有驱动都应验证快速重入10次、半程关闭后重开、禁用/销毁、静默采样与恢复。完成监听器中重播、恢复或禁用时，必须记录实际行为并确认旧完成不会污染新一轮。组合案例另按[源项目复查](project-motion-audit.md)的固定源码、层级与节拍表核对；“有相似基础效果”不能算源页面完整复刻。

## 逐项观察点

| 编号 | 观察结果 |
|---|---|
| A01 淡入 / 淡出 | 只改变透明度，让内容平滑出现；反向则逐渐消失。 |
| A02 滑入 / 滑出 | 从偏移位置滑向原位，反向时离开。 |
| A03 缩放进入 / 退出 | 从较小尺寸平滑放大到基线大小；反向缩小退出。 |
| A04 弹出进入 | 先放大超过目标尺寸，再回到基线，配合淡入。 |
| A05 弹跳进入 | 元素从上方落入，接近落点时多次弹跳并停稳。 |
| A06 翻转进入 | 目标从侧面翻转到正面并出现。 |
| A07 揭示 / 遮罩展开 | 裁剪窗口逐渐展开，露出内部内容，文字本身不拉伸。 |
| A08 模糊转清晰 | 绑定的 Image 纹理由模糊过渡到清晰，可伴随淡入。 |
| B01 按压缩小 | 按下缩小，松开回到原尺寸；自动演示展示完整按松周期。 |
| B02 按压回弹 | 按下蓄力缩小，松开短暂超过原尺寸，再恢复。 |
| B03 脉冲 / 呼吸 | 目标柔和地放大再缩回，形成一次呼吸周期。 |
| B04 抖动 | 目标快速左右交替振动，幅度逐渐减小后归位。 |
| B05 摆动 | 围绕自身支点左右摆动，最后回到初始角度。 |
| B06 冲击回弹 | 受到一次缩放冲击后衰减回弹，最终恢复基线。 |
| B07 选中态切换 | 新选中项上移或放大并变色，旧选中项恢复。 |
| B08 开关滑动 | 滑块滑向另一端，轨道颜色同步改变。 |
| C01 面板下落回弹 | 面板由上方落下，轻微越过基线后回到原位。 |
| C02 抽屉展开 | 侧边面板滑入，背景遮罩同时淡入；反向收起。 |
| C03 折叠 / 展开 | 改变裁剪容器高度，展开详情内容，保持文字原比例。 |
| C04 共享元素变形 | 同一个容器从缩略卡片位置和尺寸变为详情容器。 |
| C05 共享轴切换 | 旧页面沿一条轴离开，新页面沿同轴进入。 |
| C06 淡出后淡入 | 旧内容先淡出，中间短暂停留，再显示新内容。 |
| C07 交叉淡化 | 旧内容淡出的同时，新内容淡入。 |
| D01 数值滚动 | 数字从起点连续更新到终点，不直接跳变。 |
| D02 进度填充 | 填充比例平滑增长，达到目标后保持。 |
| D03 奖励飞入 | 奖励沿弧线飞向资源栏，落点在到达时短暂强调。 |
| D04 奖励爆散 / 汇聚 | 多个奖励先向外散开，再依次飞向接收位置。 |
| D05 逐项结算 | 条目按顺序出现并滚动数值，形成分段结算节奏。 |
| D06 星星点亮 | 星星按顺序从暗到亮，点亮时短暂放大。 |
| D07 卡牌翻面 | 卡片转到侧面时切换正反面，再转回可读正面。 |
| D08 宝箱开启 | 箱体压缩蓄力、摆动，箱盖打开，奖励随后弹出。 |
| D09 飘字 | 提示文字上浮并淡出，最终不再阻挡交互。 |
| D10 目标命中强调 | 接收图标短暂放大、变亮，再恢复原来的尺寸和颜色。 |
| E01 悬浮 | 目标缓慢上浮再回落，形成一次上下周期。 |
| E02 循环旋转 | 围绕自身中心转过一圈，可连续循环。 |

## 证据分层

静态检查证明文件/绑定结构，编译证明源码可构建。实际播放需要运行证据，输入需要交互验证。自动采样不等于人工逐帧目测；同机运行不等于另一台干净机器的兼容测试。

记录 Unity/DOTween 版本、管线、系统、构建方式、46 项结果、截图、日志和剩余问题。当前结果在工程 docs/validation.md。发布前核对源码版本、标签、包名、校验和，并下载资产核验；上传成功不等于包能运行。

## Windows 离线交付

完整解压包，保持 UIMotionGallery.exe、UIMotionGallery_Data、UnityPlayer.dll 等相邻。关闭网络，从解压目录启动，检查全部效果和分类、搜索、播放、慢放、循环、调参、复制、对比。再在未安装 Unity 的独立 Windows 环境重复；没有该环境时写“未验证”。
